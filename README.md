# 🐍 Plantilla de Entorno Python para Clase

Este repositorio contiene la configuración del entorno de desarrollo dockerizado para el curso.

## 🚀 Instrucciones de Inicio Rápido

1. Haz clic en el botón verde **"Use this template"** en GitHub para crear tu propio repositorio.
2. Abre tu terminal de **Ubuntu (WSL)**.
3. Clona tu nuevo repositorio:
   \`\`\`bash
   git clone https://github.com/TU-USUARIO/TU-NUEVO-REPO.git
   cd TU-NUEVO-REPO
   \`\`\`
4. Abre VS Code en esta carpeta:
   \`\`\`bash
   code .
   \`\`\`
5. En la esquina inferior derecha de VS Code aparecerá un aviso. Haz clic en **Reopen in Container** (Reabrir en Contenedor).
6. ¡Espera unos segundos y a programar en \`main.py\`!
